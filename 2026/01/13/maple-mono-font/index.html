Maple Mono - 开源等宽编程字体的最佳选择

序言
Maple Mono 是一款开源的等宽字体，专为代码编辑和终端设计。它支持连字（Ligatures）、多种字重以及丰富的字符集（包括 Nerd Font 图标和中文字符），是开发者和技术爱好者的理想选择。

🎨 在线自定义构建（推荐尝鲜）

如果你想快速体验并自定义字体特性（如连字、字重等），可以直接在浏览器中构建：

  1. 访问 特性测试页面
  2. 选择所需特性（如连字、图标集等）
  3. 点击页面左下角的 构建按钮 生成字体文件

📦 各系统安装方法

Windows（通过 Scoop）

首先添加 Nerd Fonts 仓库：

scoop bucket add nerd-fonts

然后安装字体（可选以下版本）：

# 基础版（TTF）
scoop install Maple-Mono

# Nerd Font 版（含图标）
scoop install Maple-Mono-NF

# Nerd Font 中文版
scoop install Maple-Mono-NF-CN

macOS / Linux（通过 Homebrew）

使用 --cask 参数安装：

# 基础版
brew install --cask font-maple-mono

# Nerd Font 版
brew install --cask font-maple-mono-nf

# 中文版（带连字）
brew install --cask font-maple-mono-nf-cn

💡 提示：Homebrew 还提供其他变体（如常规字重、无连字版本），可在官方文档中查看。

Arch Linux（通过 ArchLinuxCN 仓库）

推荐使用 ArchLinuxCN 仓库（可单独下载包）：

# 基础连字版（无微调）
paru -S ttf-maplemono

# Nerd Font 版（无微调）
paru -S ttf-maplemono-nf-unhinted

# Nerd Font 中文版（无微调）
paru -S ttf-maplemono-nf-cn-unhinted

⚠️ 注意：AUR 源需下载完整包组，包名以 maplemono- 开头，不推荐使用。

NixOS / Nixpkgs（Linux 或 macOS）

在系统配置中添加字体包：

fonts.packages = with pkgs; [
  maple-mono.truetype       # 连字版（TTF，无微调）
  maple-mono.NF-unhinted    # Nerd Font 版
  maple-mono.NF-CN-unhinted # Nerd Font 中文版
];

更多变体（如无连字版、可变字重版）可在官方文档中查看。

📋 字体版本说明

版本标识 说明
Ligature（连字） 将代码符号（如 => 、!=）转换为更美观的合字
NF（Nerd Font） 集成常用图标（如文件夹、Git 分支等），适合终端和编辑器
CN（中文） 包含中文字符支持
hinted/unhinted 微调版优化小字号显示，无微调版保持原样
OTF/TTF/WOFF2 不同字体格式，TTF 最通用

✨ 小结

Maple Mono 提供了灵活的自定义选项和多平台安装支持，无论是通过包管理器一键安装，还是在线定制构建，都能满足个性化需求。

推荐安装方式：

  • Arch 用户：优先使用 ArchLinuxCN 仓库
  • Windows 用户：使用 Scoop
  • macOS/Linux 用户：使用 Homebrew
